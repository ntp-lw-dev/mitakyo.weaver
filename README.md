mitakyo.weaver. A Personal Bio Site
A single-page personal biography website built with vanilla HTML, CSS, and JavaScript.
No frameworks or libraries used beyond Font Awesome for icons and Google Fonts for typography.

Sections:
  Banner — Full-screen hero with a background illustration, name in both English and Japanese, and navigation buttons
  About Me — Three-column layout with character reference cards on both sides and a personal bio in the centre
  VTuber — Introduction to both VTuber personas (Mitasa & KuKyo) with model showcase images
  Events — Convention attendance tracker with event cards showing country flag, event name, location, date, and attendance status
  Contacts — Social media link grid covering Facebook, X, Bluesky, Twitch, YouTube, and TikTok
  Gallery — Past commission artwork displayed in a 3-column grid with artist credits

Features:
  CSS variable theming system for easy colour changes
  Scroll-reveal animations using IntersectionObserver
  Active navigation highlight that tracks the current section
  Responsive layout with mobile breakpoints
  Fixed navigation bar with frosted glass backdrop effect
  Gradient overlay system for background images

Built with: HTML5, CSS3, JavaScript, Font Awesome 6.7.2, Google Fonts.
